For hackclub week 1, i've made a flight controller for a rocket. It handles 4 pyro channels (2 on top, 2 on the bottom). It has an stm32 for the processor, as well as several other sensors such as barometric, altitude, gps, radio, etc. It recieves power from a 2s lipo. Everything was built around breakout boards, so if the rocket experiences any rough landing or the chips just break in general, it should be easy to replace and won't brick the entire board if it does break.
